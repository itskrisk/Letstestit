# Custom Rules

- **Always update history.md**: At the end of every prompt or major task, you MUST append a detailed summary of the prompt, the actions taken, any failures encountered, and the final working solution to the history.md file in the root directory. This is a critical requirement for maintaining the project log.

- **STRICT DESIGN RULE - NO PADDING / NO CARD BOXES**: Never use card padding, rounded container boxes (`rounded-3xl`/`rounded-2xl`), or padded container backgrounds (`bg-white/10 p-8`) around content or text. Always design with clean, classy, unboxed editorial typography, edge-to-edge section dividers (`border-t`/`border-b`), and transparent bottom-line input fields.
