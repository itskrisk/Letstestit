## ⚠️ Drafting note

This document is a **pre-population drafting template** for the BRS Form CR1 (Application for Registration of a Company). It is **not** the official BRS form. The actual filing must be done on the BRS eCitizen portal using the current prescribed electronic form. This template is provided so the founders and the Advocate can pre-populate and verify the data before live entry.

The fields below mirror the typical CR1 information set. **Verify every field against the current BRS eCitizen portal** before filing — fields, validation rules, and required attachments may have changed.

This template does **not** include any fee, official reference number, or signature image. It only consolidates the data the founders must supply.

---

## DOCUMENT PURPOSE

Provides the data set required to file Form CR1 (Application for Registration of a Company) with the Business Registration Service via the eCitizen portal.

## LEGAL BASIS

- **Companies Act, 2015** — Part II (incorporation procedures).
- **Business Registration Service** — eCitizen portal current process and Form CR1 requirements.
- **Companies (Beneficial Ownership Information) Regulations** — for the Beneficial Owner section of CR1.

## WHO USES IT

- **Founders** — provide the underlying data and supporting documents.
- **Advocate / Filing Agent** — enters the data on the BRS eCitizen portal on the founders' behalf.
- **BRS** — receives the application.

## LEGAL REVIEW FLAGS

1. **Current BRS portal.** The BRS eCitizen portal UI changes periodically. The Advocate must verify each field label, validation rule, and required attachment against the live portal before entry.
2. **Director residence address.** CR8 traditionally requires a director's residential address. The Advocate should confirm whether BRS still requires this for all directors in 2026.
3. **Witness requirement.** The Advocate should confirm whether subscriber and director signatures require a witness, Commissioner for Oaths, or Advocate's attestation for filing.
4. **Beneficial Owner threshold.** Verify the current BOI threshold (typically 10% or significant control) and the exact information required.
5. **Fee amount.** Do not include any fee figure here. Confirm the current incorporation fee on the BRS fee schedule before payment.
